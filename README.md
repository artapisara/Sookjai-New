# สุขใจ — แอพเตือนกินยา & นัดหมอ (ต้นแบบ v0.1)

เว็บแอพไฟล์ล้วน (HTML/CSS/JS) ไม่ต้อง build — อัปขึ้น Vercel ได้ทันที

## ไฟล์ในโปรเจกต์
- `index.html` — หน้าหลัก
- `styles.css` — หน้าตา สีสัน
- `app.js` — การทำงานทั้งหมด (ข้อมูลเก็บในเครื่องผู้ใช้ด้วย localStorage)
- `manifest.json`, `icon.svg` — ให้ "เพิ่มไปยังหน้าจอโฮม" แล้วเปิดเหมือนแอพ

## ทางที่ 1: ผ่าน GitHub (ไม่ต้องใช้คำสั่ง)
1. สมัคร/ล็อกอิน github.com → กด **New repository** ตั้งชื่อ `sukjai` → Create
2. กด **uploading an existing file** → ลากไฟล์ทั้ง 6 ไฟล์ในโฟลเดอร์นี้ลงไป → Commit changes
3. ไปที่ vercel.com → ล็อกอินด้วย GitHub → **Add New… → Project**
4. เลือก repo `sukjai` → Framework Preset เลือก **Other** → กด **Deploy**
5. ได้ลิงก์ เช่น `sukjai.vercel.app` เปิดในมือถือได้เลย
   (แก้ไฟล์ใน GitHub ทีหลัง Vercel จะอัปเดตเว็บให้อัตโนมัติ)

## ทางที่ 2: ใช้ Vercel CLI (ถ้ามี Node.js ในเครื่อง)
```bash
cd sukjai
npx vercel        # ครั้งแรกจะให้ล็อกอินและตอบคำถาม กด Enter ตามค่าเริ่มต้นได้
npx vercel --prod # ปล่อยเวอร์ชันจริง
```

## ติดตั้งบนมือถือ
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "เพิ่มลงในหน้าจอหลัก"

## ทดลองในเครื่องตัวเอง
ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย

## ข้อจำกัดของต้นแบบ
- ข้อมูลอยู่ในเครื่อง/เบราว์เซอร์ที่ใช้เท่านั้น ไม่ซิงก์ข้ามเครื่อง → ใช้ปุ่ม "ส่งออก/นำเข้า" ในหน้าครอบครัวเพื่อสำรอง
- แจ้งเตือนเด้งได้เฉพาะตอนเปิดแอพค้างไว้ — แอพจริงบน Play Store / App Store จะเตือนได้แม้ปิดแอพ
- ใช้ประกอบการดูแล ไม่แทนคำแนะนำของแพทย์หรือเภสัชกร
